Plandaro

Finding one person in thousands of event photos.

Role
Software Engineer, Full Stack
When
April 2026 to present
Where
Remote

What I did

  1. Ingest. Bulk uploads go straight onto a queue. Celery workers take it from there, so the API never blocks and requests never time out.
  2. Compress. Every photo is compressed in the background, automatically.
  3. Embed. InsightFace turns each face it finds into an embedding: a vector that lands close to other photos of the same person.
  4. Index. The vectors live in PostgreSQL with pgvector, under an HNSW index.
  5. Match. A new face is matched against all of them in under a second, with about 98% matching accuracy.

Rest of the stack

I architected and scaled this pipeline at Plandaro, an event planning marketplace. Beyond the photo pipeline, I worked on its technical architecture across the stack.
